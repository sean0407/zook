# Zook 開發規劃

進度的唯一依據。流程見 [CLAUDE.md](../CLAUDE.md)「每個項目的流程」。

狀態：⬜ 未開始　🟨 進行中　✅ 完成　⏸ 暫緩

## 已決定的事（2026-11-18）

- Bot 建立、修改、刪除排程，每次都要使用者核准，不論權限模式。
- Mac 關機時不跑排程，不做雲端主機。
- 進階選項（思考強度、各家特色）收在「進階」裡，主畫面保持簡單。
- 開發採「逐階段」：使用者核准該階段的驗收條件，之後依序做完，卡住或驗收失敗才停。

## 已完成（v0.6.0 以前）

Bot 與分組、群聊（管理員主持、互相交接）、多帳號、備用模型自動切換、共用 Skill／連接器／插件、匯入 Zook 與設定包、內建 Gmail（個人帳號）、記憶、知識庫、上網搜尋開關、用量、單一 Bot 排程、iPhone App、自動更新。

### 第 1 階段驗收報告（v0.7.0）

- D1：通過。表單對象下拉列出 Bot 與群組；群組排程以「由 排程 發起」發話、群組忙時回 409 並等待；刪群組連帶刪排程（`schedule_test`、瀏覽器實測）。
- D4：通過。只一次執行後停用並顯示「已完成」；每月 31 號遇小月在月底；舊排程照常（`ScheduleTimes`、瀏覽器實測）。
- D6：通過。保留最近 20 次；「紀錄」點一筆會開到該訊息並標示（瀏覽器實測）。
- D3：通過，點通知未驗證。Preview 版以真實 Codex 跑排程，App 把通知交給 macOS 成功；macOS 第一次會先問是否允許通知。點通知開啟對話在瀏覽器以相同程式碼驗證，真實點擊待使用者驗收。
- E1：Codex、Claude、Grok 通過（列出不用核准；建立、修改、刪除在三種主動性都要核准；上限 50）。**Gemini 未通過**：Gemini CLI 目前完全沒有接 Zook 工具，這台 Mac 也沒裝 Gemini，改列 E6。
- D2：通過。真實 Codex、Claude、Grok 一句話建立排程；拒絕時不建立且 Bot 說明；群組裡建出群組排程；「全部允許」的 Grok 仍要核准；手機 API 拿到同樣的核准說明。手機實機待使用者驗收。
- G1：通過。寄信卡片寫出收件人與主旨；排程執行中要核准時發通知，真實 Codex、Claude 等 100 秒後核准仍正常完成；逾時視為拒絕並寫入紀錄（以縮短的等待時間測試）。

順帶修好的既有問題（Grok）：Zook 工具在 App 裡一直沒接上（嚴格沙箱無法啟動 Xcode 內的 Python）；Grok 用短名稱呼叫工具時被擋；新版 Grok 不接受 `--add-dir`，「整台 Mac」「指定資料夾」的 Grok Bot 無法啟動。Grok 的檔案工具現在只在工作資料夾，整台 Mac 改靠指令列；「指定資料夾」的 Grok 碰不到該資料夾。

### D1 群組排程
1. 排程表單的對象下拉同時列出 Bot 和群組。
2. 選群組的排程，時間到會在群組以「由 排程 發起」發話，照平常的群組流程討論，最後由主持 Bot 給結論。
3. 群組正在討論時，等它結束再開始；6 小時後仍在忙就記為錯過。
4. 刪除群組時，它的排程一起刪除；排程卡片顯示群組名稱與頭像。
5. 「立即執行」對群組排程也有效。

### D4 單次與更多頻率
1. 重複方式增加：只一次（選日期）、每小時、每月（選幾號）。
2. 只一次的排程執行後自動停用，卡片顯示「已完成」。
3. 每月選 29–31 號時，遇到沒有這天的月份在該月最後一天執行。
4. 舊版建立的排程照常運作。

### D6 執行紀錄
1. 每個排程保留最近 20 次執行：時間、結果（已執行／失敗／錯過）、原因。
2. 卡片上「紀錄」打開列表，點其中一筆跳到那次的對話位置。
3. 刪除排程時紀錄一起刪除。

### D3 完成通知（Mac）
1. 排程執行完（回覆完成、失敗或錯過）跳出 Mac 通知，標題是對象名稱，內文是結果的第一句。
2. 排程執行中出現需要核准的動作時，也跳通知。
3. 點通知會開啟 Zook 並切到該對話。
4. 設定裡有「排程通知」開關，預設開啟。

### E1 Zook 動作工具（排程）
1. Codex、Claude、Grok、Gemini 的 Bot 都拿得到一組 Zook 工具：列出、建立、修改、刪除排程。設定一次，全體共用。
2. 列出不用核准；建立、修改、刪除都要核准。
3. 工具只能管理排程，不能改權限、存取範圍、模型、帳號或其他設定。
4. 上限：全部最多 50 個排程；超過時工具回覆原因。
5. 每個 Bot 的工作說明裡告訴它「可以幫使用者建立排程」。

### D2 Bot 在對話裡建排程
1. 在 Bot 對話說「每天早上 10 點…」，Bot 提出排程，Mac 和手機都出現核准卡片，寫出對象、內容、時間與頻率。
2. 按核准才建立，Bot 回覆建好了什麼；按拒絕不建立，Bot 回覆已取消。
3. 在群組裡說，建出來的是群組排程。
4. 權限模式是自動核准的 Bot 也一樣要核准。
5. 建好的排程出現在排程頁，和手動建立的完全一樣。

### G1 對外動作一律核准
1. 寄信、建立／修改／刪除排程，不論權限模式都要核准；核准卡片寫出要做什麼。
2. 排程無人看管時遇到核准請求，等待最多 24 小時，期間發通知；逾時視為拒絕，記入執行紀錄。

### 第 1 階段需要使用者驗收
- 在 Zook 視窗裡用真實的 Claude 或 Codex 說一句話建立排程。
- 在手機上按核准。
- 收到 Mac 通知、點通知開啟對話。
- 隔天確認排程在 10:00 自動執行。

## 之後的階段（驗收條件在開始該階段前補上）

## 第 2 階段：對話體驗

目標：和 Bot 對話的手感接近 ChatGPT／Claude：可以開新對話、找回舊對話、丟檔案和截圖、不滿意就重來、需要時讓它想深一點或先給計畫。

依序：B1 → B3 → B2 → A3 → B5。

| 編號 | 項目 | 狀態 |
|---|---|---|
| B1 | 每個 Bot 多個對話、歷史清單與搜尋 | ⬜ |
| B3 | 重新回答、修改問題重送、換模型重答 | ⬜ |
| B2 | 附件：拖放檔案、貼上截圖 | ⬜ |
| A3 | 思考強度（快速／標準／深入） | ⬜ |
| B5 | 先規劃開關 | ⬜ |

### B1 每個 Bot 多個對話
1. Bot 對話畫面有「新對話」按鈕；新對話從空白開始，Bot 不會看到其他對話的內容（記憶與知識庫照舊共用）。
2. 有對話清單：依最近使用排序，標題自動取第一句，可以改名、刪除（刪除前確認）。
3. 搜尋框可以搜所有 Bot 的對話內容，點結果開到該對話的那則訊息。
4. 舊版的對話成為每個 Bot 的第一個對話，內容不變。
5. 排程送出的訊息進到該 Bot 的「排程」對話，不打斷你正在進行的對話；排程紀錄與通知仍能開到正確位置。
6. 手機看到每個 Bot 最近的對話，可以在其中繼續聊天；切換對話清單留到第 5 階段 F1。

### B3 重新回答、修改問題重送、換模型重答
1. Bot 最後一則回覆下方有「重新回答」：用同一個問題再回答一次，舊回覆被取代。
2. 自己的最後一則訊息可以「編輯」，改完重送，之後的回覆被取代。
3. 「換模型重答」下拉列出已安裝可用的模型；重答只用這一次，不改 Bot 設定，回覆下方註明用了哪個模型。
4. Bot 正在回覆、或回覆時曾經改過檔案或對外動作時，重答前先提醒「上一次已經做過的動作不會復原」。
5. 群組不提供這三個功能（第 4 階段再說）。

### B2 附件
1. 可以把檔案拖進對話框、按「＋」選檔案，或直接貼上截圖；送出前看得到縮圖或檔名，可以移除。
2. 每則訊息最多 10 個檔案，單檔 20 MB；超過時說明原因，不送出。
3. 檔案存進該 Bot 的工作資料夾，Codex、Claude、Grok 都讀得到；圖片 Codex 直接看圖，Claude、Grok 用自己的讀檔工具看。
4. 對話裡顯示附件（圖片顯示縮圖，點開放大；其他檔案顯示檔名）。
5. 群組也可以附檔，所有成員都讀得到。
6. 手機暫不支援附檔（第 5 階段 F1）。

### A3 思考強度
1. 對話框旁有下拉：快速／標準／深入，預設「標準」，只影響之後的訊息；在「進階」裡可以設定每個 Bot 的預設值。
2. Codex、Claude、Grok 各自對應到自己的強度設定；CLI 不支援時選項顯示「這個模型不支援」並停用。
3. 回覆下方可以看到這次用了哪個強度（只有不是「標準」時才顯示）。

### B5 先規劃開關
1. 對話框旁有「先規劃」開關。開啟時 Bot 只提出計畫（要做什麼、會動到什麼、需要哪些核准），不動檔案、不執行指令、不做對外動作。
2. 計畫下方有「照計畫執行」按鈕，按下後 Bot 依計畫執行，核准規則照常。
3. 開關只對這一則訊息有效，送出後自動關閉。

### 第 2 階段需要使用者驗收
- 在 Zook 視窗開新對話、從清單切回舊對話、用搜尋找到一則舊訊息。
- 貼一張截圖問 Claude 或 Codex 圖裡是什麼。
- 對一則回覆按「換模型重答」。
- 用「深入」問一個難題，再用「先規劃」讓 Bot 提計畫、按照計畫執行。
