# Zook 0.13 系列進度

依 `Zook-0.13-開發提示詞` 進行。對話被壓縮後，以這份檔案為準接續。

## 準備工作

- 分支 `stage/7`，從 `item/error-kinds` 開出（錯誤分類集中，併入 0.13.0）。
- 驗收腳本 `scripts/acceptance.py`：用真實 CLI 檢查 20 項。基準存在 `docs/0.13-baseline.json`。
  - 用法：`python3 scripts/acceptance.py --compare docs/0.13-baseline.json`，結束碼 0 表示沒有變差。
- 基準結果：20 項都通過過。
  - 第一次執行 19 項通過；「動作前先問」失敗是檢查寫錯（選到不需核准的 `zook_remember`），改用一定要核准的「建立排程」後通過。
  - 第二次執行時 Antigravity 的額度剛好用完（Gemini 週額度原本只剩約 3%）。這是外部狀況，腳本把額度用完標為「略過」，不算變差。
  - **影響**：額度重置前，Antigravity 的檢查都會被略過。項目 1 需要它的串流實測，到時改用 Antigravity 裡另一組模型的額度來測，測不了就如實記錄。

## 替使用者做的決定

- 驗收腳本的核准檢查用「建立排程」而不是「記住一件事」，因為後者在設計上本來就不需要核准。
- 額度用完視為略過而不是失敗。
